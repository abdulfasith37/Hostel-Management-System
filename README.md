# 🏢 University Hostel & Accommodation Management System

> A streamlined web application designed to manage university hostel room allocations, resident lookups, warden duties, and maintenance tickets efficiently.

---

## 📌 About the Project

The **University Hostel & Accommodation Management System** is a lightweight, responsive web application developed as part of our university web development curriculum. 

It replaces manual paperwork with a centralized digital system, providing three dedicated roles:
- **🎓 Student Portal:** Search by Registration Number to view assigned rooms, roommates, and track maintenance requests.
- **🛡️ Warden Portal:** Look up supervised blocks, room occupancy statistics, and pending hostel requests.
- **⚙️ Admin Dashboard:** Complete control over hostels, blocks, room inventory, bed allocations, and maintenance oversight.

---

## 🛠️ Built With

* **Backend:** PHP & MySQL
* **Frontend:** HTML5/CSS and JS
* **Tools:** Apache (XAMPP), VS Code & GitHub
